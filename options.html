sEnd2End
On-device end-to-end encryption
Keys never leave this device

This extension can hold multiple RSA keys on this device: a personal key, site-specific keys, and optional group keys you share with friends. Connected sites see only public keys you authorize for that origin.

Keys

Personal keys can be reused across sites. Site keys only work on the origin they were created for. Group keys are for a shared ciphertext: everyone who imports the same backup can decrypt.

Backup

A passphrase-protected backup is the only way to recover this key on another browser or machine. Store it offline.

Connected sites

These origins can ask the plugin to encrypt, decrypt, and prove key possession. Add one from the toolbar popup on that tab, or with the site’s Connect sEnd2End button.

Who can open data

On a connected site you pick recipients by role or by a shared group key. For a friends group, wrap once to the group public key so the site stores a single ciphertext everyone in the group can open.

  • Uploader / sender — always keeps a wrap for data they encrypt.
  • External auditor — invited reviewers who must open proof.
  • Staff — owners or operators who must open the data.
  • Platform admin — only if an admin must open it. Leave off so operators cannot read it.
Without this extension

Some sites can still generate a key and encrypt in the page with WebCrypto. That is a fallback: a changed site build could see plaintext after decrypt. Keep sEnd2End installed, connect the site, and hold a passphrase backup.
